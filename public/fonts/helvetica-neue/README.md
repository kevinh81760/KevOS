# Helvetica Neue Font Files

Place your Helvetica Neue font files here:

## Required Files:
- `HelveticaNeue-Regular.woff2` and `.woff`
- `HelveticaNeue-Medium.woff2` and `.woff`
- `HelveticaNeue-Bold.woff2` and `.woff`

## Note:
If your font files have different naming (e.g., `HelveticaNeue-Regular.ttf`), you'll need to:
1. Convert them to `.woff2` format using Transfonter or CloudConvert
2. Name them exactly as listed above

These fonts are used for body text and headings throughout your portfolio.
