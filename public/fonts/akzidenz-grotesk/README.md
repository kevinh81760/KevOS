# Akzidenz-Grotesk Font Files

Place your Akzidenz-Grotesk font files here:

## Required Files:
- `AkzidenzGrotesk-Regular.woff2` and `.woff`
- `AkzidenzGrotesk-Medium.woff2` and `.woff`

## Note:
If your font files have different naming, you'll need to:
1. Convert them to `.woff2` format using Transfonter or CloudConvert
2. Name them exactly as listed above

This font is used in the About page for paragraph text.
