# Bjork Font Files

Place your Bjork font files here:

## Required Files:
- `Bjork-Regular.woff2` and `.woff`

## Note:
If your font file has a different naming or format, you'll need to:
1. Convert it to `.woff2` format using Transfonter or CloudConvert
2. Name it exactly as listed above

This font is used in the KevOS title animation component.
